# sail-suitely

Public landing page + privacy policy for **Sail Suitely** (iOS luxury-cruise discovery app;
internal repo name "Anchored"). A product of **3 Bears Studio LLC** (Apopka, Florida, USA).

Served by GitHub Pages under the studio domain: **https://3bears.studio/sail-suitely/**
(the `3bearsstudio` org's root Pages site carries the custom domain, so this project repo is
served under it automatically — see `~/appDevelopment/md/studio-identity-web-standards.md`).

- `index.html` — landing page
- `privacy.html` — privacy policy (App Store privacy URL + affiliate-network requirement)
- `.nojekyll` — required so GitHub Pages serves files verbatim

Self-contained HTML/CSS, no external assets. Update = edit + push (Pages auto-rebuilds).
